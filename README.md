# 截图录屏 · SnipRecord（WidBar 小组件）

放在任务栏上的 WidBar 小组件：一键截图、全屏截图、截图标注、矩形/窗口录屏、GIF 导出、屏幕取色，支持全局快捷键。

> ⚠️ 当前版本只在 Linux 上做过编译检查，**尚未在真实 Windows 设备上测试**，可能存在运行时问题。

## 功能
- **任务栏三个按钮**（仿系统截图工具风格）：
  - 📷 **截图**：弹出小菜单：「截图」（调用 Windows 截图工具，按设置里的默认模式：矩形 / 窗口 / 自由形状）、「全屏（当前屏幕）」、「全屏（所有屏幕）」。
  - 🎬 **录屏**：弹出小菜单，选择「矩形录屏」或「窗口录屏」。窗口录屏进行中按钮变红并显示计时，点一下即停止。
  - 💧 **取色**：冻结屏幕后用放大镜取色，点击即复制颜色值（HEX / RGB / HSL 可选）。
- **弹出面板**：大按钮截图 / 录屏 / 取色，可切换截图模式（矩形 / 窗口 / 自由形状 / 全屏）与录屏模式（矩形 / 窗口）；麦克风开关和「录成 GIF」开关；最近 8 条截图/录屏（缩略图，点击打开，可复制、在文件夹中显示；截图可点「标注」打开编辑器，录屏可点「GIF」导出 GIF，显示进度，再点一次取消）；最近取过的颜色色块（点击按所选格式复制）。
- **全屏截图**：自研，不经过截图工具。可截鼠标所在的**当前屏幕**或**所有屏幕**（拼成一张图），保存为 PNG 并复制到剪贴板，加入最近记录。默认范围可在设置里选择。
- **截图标注编辑器**：从最近记录的「标注」按钮打开，或在设置里开启「截图后打开标注」。工具：选择/移动（V）、画笔（P）、荧光笔（H）、箭头（A）、直线（L）、矩形（R）、椭圆（E）、文字（T）、马赛克（M）、序号标记（N）、裁剪（C）；6 种颜色 + 自定义颜色，细 / 中 / 粗三档；撤销 / 重做（Ctrl+Z / Ctrl+Y）；复制（Ctrl+C）、保存为副本或覆盖原图（Ctrl+S）、另存为（Ctrl+Shift+S，PNG / JPEG / BMP）；按原图分辨率导出。
- **GIF**：录屏可单独导出为 GIF（保留 MP4），也可开启「录成 GIF」，录完自动转换并删除 MP4（窗口录屏和截图工具矩形录屏都适用）。帧率 5 / 10 / 15 / 20，最大宽度 480 / 640 / 800 / 1080 / 原始大小。
- **全局快捷键**（可在设置里修改、清除或重置，也可整体关闭）：

  | 功能 | 默认快捷键 |
  | --- | --- |
  | 截图 | Ctrl+Alt+A |
  | 全屏截图 | Ctrl+Alt+F |
  | 矩形录屏（截图工具） | Ctrl+Alt+R |
  | 窗口录屏（再按一次停止） | Ctrl+Alt+V |
  | 屏幕取色 | Ctrl+Alt+C |
  | 标注最近截图 | 未设置 |

  注意：**Ctrl+Alt+A 经常与 QQ / 微信的截图快捷键冲突**。被其他程序占用时设置页会用红字提示「已被占用」，可在设置里改成其他组合。
- **设置**：默认截图模式、延时（0 / 3 / 5 / 10 秒）、截图工具同时自动保存、截图后打开标注、全屏截图默认范围（当前屏幕 / 所有屏幕）、截图保存位置、录屏保存位置、窗口录屏时录制麦克风、GIF（帧率、最大宽度、录成 GIF）、快捷键、颜色格式、任务栏宽度。

## 实现说明
- **截图、矩形录屏**：通过系统「截图工具」的 `ms-screenclip:` 协议（API 1.2）完成，结果经 `sniprecord://` 回传，文件复制到你设置的保存位置（默认 `图片\Screenshots\SnipRecord`、`视频\SnipRecord`）。
- **窗口录屏为自研**：基于 `Windows.Graphics.Capture` 捕获单个窗口，Media Foundation 编码为 H.264 + AAC 的 MP4；
  同时录制**该窗口所属程序的声音**（进程环回录音），可选叠加**麦克风**。录制时窗口外有红色边框和可拖动的控制条（暂停 / 继续 / 停止），边框与控制条不会被录进视频。
- **取色**：自研全屏放大镜，支持方向键微调（Shift 加速），Enter/空格/左键确认，Esc/右键取消。

## 限制
- 需要 Windows 11 上较新版本的「截图工具」（支持 `ms-screenclip` API 1.2）；不支持时面板会显示提示，请到 Microsoft Store 更新截图工具。
- 窗口录屏的程序声音需要 Windows 11（build 20348 及以上）；UWP 应用窗口可能录不到声音。录屏期间窗口大小变化时画面按初始尺寸等比缩放。
- 最小化的窗口无法录制；静止画面时视频为可变帧率（正常现象）。
- 矩形录屏的声音、麦克风由截图工具自身控制。
- 安装包为自签名证书，安装时需要管理员权限信任证书。
- 尚未在真实 Windows 上测试（只做过编译检查）。
- GIF 转换较长的录屏会比较慢（逐帧抽取）；GIF 调色板质量尚未调优。

## 安装
1. 到 [Releases](https://github.com/hq970123/SnipRecord/releases) 下载对应架构的 `SnipRecord_x64.zip`（大多数电脑）或 `SnipRecord_ARM64.zip`。
2. 解压后双击 `Install.bat`（会请求管理员权限以信任自签名证书并安装）。
3. 打开 WidBar，在控件目录里找到「截图录屏」，拖到任务栏。

## 隐私
所有截图、录屏和颜色只保存在本机，不会上传。详见 [PRIVACY.md](PRIVACY.md)。

## 构建
推送到 `main` 后由 GitHub Actions（`.github/workflows/build.yml`）构建 x64 / ARM64 的 MSIX 并发布 Release（`build-<序号>`）。
本地：Visual Studio 2022+，.NET 10，打开 `SnipRecord.sln`，以 `SnipRecord (Package)` 为启动项目。
